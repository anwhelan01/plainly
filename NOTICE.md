# Notice

## Google developer documentation style guide

Portions of Plainly's writing rules operationalize the
[Google developer documentation style guide](https://developers.google.com/style/).

Google licenses that page content under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) unless a page says
otherwise. Code samples in the guide are under
[Apache 2.0](https://www.apache.org/licenses/LICENSE-2.0).

This project is independent and is not endorsed by Google.

## Anti-slop appendix

The Claude-lish / Chat-lish appendix (openers, wrappers, brochure words, hedges)
is original to Plainly. It is not part of Google's guide.
